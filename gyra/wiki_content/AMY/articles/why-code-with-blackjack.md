# Why code with blackjack

Unlike traditional systems that use variables to store player actions, Blackjack allows writers to access all player actions in real-time. This feature allows for nuanced storytelling that incorporates even the most subtle actions, such as opening a door, looking at a vase, or ignoring someone.
