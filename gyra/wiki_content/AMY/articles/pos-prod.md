[wip] 3.6 Pathfinding AI
Our Pathfinding method for pursuing characters involves a set of points for the character to follow. The level editor can determine the order in which the character follows the points. Additionally, this function allows the AI to become aware of the player's proximity to one of these points and begin slowly moving towards the player without being intrusive, encouraging players to stay alert.
[wip] 3.7 Debug Menu
To optimize our work process, we've developed code that includes various elements and functions to make our work more efficient. The debug menu has several features, including detailed scene statistics, a text console to view user-performed functions in writing, and a text section displaying buttons with different assigned functions.

This section displays key scene details such as frames per second and the percentage of CPU or GPU usage on the computer or console.

This text displays the button series used for various functions such as checking the controller being used, jumping between scene spawns, or enabling a level designer to pass through walls.



This menu section notifies editors about important scene details, such as the spawn point used by Amy, the number of colliders in the scene, and the device running the game.


[wip] 3.8 Inventory
Amy's Escape will have a basic inventory system, with objects displayed in boxes that gradually enlarge in a visually pleasing and organized manner. The inventory will appear after the screen darkens slightly and will include a text box for exiting the inventory. Players will be able to examine items, but combining objects will not be a feature.
