# Smaller File Sizes

Unity games generally have smaller file sizes compared to their Unreal Engine counterparts. This is crucial for mobile games, as smaller file sizes lead to faster download times and less storage space required on users' devices. For example, Genshin Impact's mobile version is around 3-4 GB in size, while an Unreal Engine game with similar visuals and content could easily exceed 10 GB.
